// what it does

Three jobs. Done well.

No subscriptions, no cloud round-trip, no proprietary protocol. Your phone, your computer, your network.

</>

Extend display

Use your phone or tablet as a real second monitor. MJPEG over LAN, ~30 FPS, auto resolution matching.

↗

WiFi mouse + keyboard

Trackpad gestures, full keyboard, and 40+ system shortcuts (Cmd+Tab, mission control, media). WiFi-Mouse-style, but open.

⇄

File drop

Drag a file onto the app or tap Send on the phone. Direct LAN transfer, progress bar, image previews.

// flow

Three taps to connected.

Zero configuration. Auto-discovery over UDP, auto-reconnect, auto-resolution.

Start the server

Open Vior on your computer. One button — Start Server. A QR code appears.

Open the mobile app

Vior auto-discovers any server on your LAN. Tap to connect, or scan the QR.

Stream & control

Use the phone as a second display, send files, or jump to the Remote tab for trackpad + shortcuts.
