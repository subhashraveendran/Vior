// what it does

Everything in one app.

No accounts. No cloud. No subscription. Just your phone, your computer, and your network.

Second screen

Use your phone or tablet as a real extra monitor — drag windows onto it. Or mirror your main screen to share.

Wi-Fi or USB cable

Same network? Auto-discovery finds your computer. No Wi-Fi? Plug the cable in — works without any router.

File transfer

Drag a file onto the desktop app, or tap Send on the phone. Goes directly between devices — never touches a cloud.

Trackpad + keyboard

Phone becomes a wireless trackpad with right-click, scroll, and a full keyboard with 40+ system shortcuts.

Pair-code security

One-time 6-digit code on the desktop. Trusted devices reconnect instantly — no re-pairing.

Single binary

Download one app, double-click to run. No installers, no drivers (Windows has an optional one), no setup wizard.

// how it works

Connect in 3 steps.

No accounts, no setup wizard, no driver install. Just three taps.

1. Start on computer

Open Vior on your Mac, Linux, or Windows machine and click Start Server. You'll see a QR code and a 6-digit pair code.

2. Open on phone

Open the Vior Android app (or any browser on iOS). It finds your computer automatically over Wi-Fi, or you can scan the QR code.

3. Enter pair code · once

Type the 6-digit code shown on the desktop. From then on, that device is trusted — it auto-connects without asking again.
